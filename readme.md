# 🎙️ Audio Silence Remover & AI Transcriber (Rust)

Высокопроизводительное CLI / Desktop-приложение на Rust для быстрой очистки аудиофайлов от тишины, пауз и шумов с поддержкой **бесплатного ИИ-распознавания речи (Groq Whisper API)** и **редактирования текста (DeepSeek API)**.

Представляет собой бесплатную альтернативу сервисам вроде Gling без каких-либо подписок, ограничений по длительности или платных тарифов.

---

## ✨ Основные возможности

- 🚀 **Мгновенная очистка тишины**: Удаление неинформативных пауз и запинок с помощью локального FFmpeg.
- 🗣️ **Без «съедания» букв**: Встроен мягкий отступ (padding) и мгновенный запуск реакции VAD, сохраняющие шёпот и первые звуки слов.
- 🤖 **ИИ-распознавание речи (STT)**: Интеграция с супербыстрым бесплатным **Groq Whisper-large-v3 API**.
- 🧠 **Умная редакторская правка**: Автоматическое исправление грамматики, расстановка пунктуации и разбивка на абзацы через **DeepSeek API**.
- 🖱️ **Интерактивный Drag-and-Drop режим**: Поддержка запуска простым двойным кликом по `.exe` и перетаскиванием файлов в окно консоли.
- ⚙️ **Автономность**: Автоматическая загрузка FFmpeg при первом запуске, если он отсутствует в системе.
- 📦 **0 тяжелых внешних зависимостей**: Написан на чистом Rust для обеспечения максимальной скорости работы и компактного размера бинарника.

## 🛠️ Быстрый старт

### Требования
- Установленный компилятор **Rust** и менеджер пакетов `cargo` ([rustup.rs](https://rustup.rs/)).

### Сборка из исходников

1. Клонируйте репозиторий или скачайте исходный код:
   ```bash
   git clone https://github.com/mako986/Silence-Remover.git
   cd audio_silence_remover
   ```

2. Соберите оптимизированный исполняемый файл:
   ```bash
   cargo build --release
   ```

3. Готовый файл находится в директории:
   - **Windows:** `target\release\audio_silence_remover.exe`
   - **Linux / macOS:** `target/release/audio_silence_remover`

## 🚀 Способы использования

### 1️⃣ Интерактивный режим (Двойной клик)
1. Запустите `audio_silence_remover.exe`.
2. Перетащите аудио/видео файл прямо в окно терминала и нажмите `Enter`.
3. Выберите пресет чувствительности (`normal`, `pure`, `noisy`).
4. (Опционально) Подтвердите ИИ-расшифровку и введите API-ключи при запросе.

---

### 2️⃣ Перетаскивание файла на иконку
Перетащите файл `.mp3`, `.wav`, `.mp4` или `.m4a` прямо мышкой на иконку `audio_silence_remover.exe`. Программа автоматически обработает файл и сохранит результат с суффиксом `_clean.mp3` рядом с оригинологией.

---

### 3️⃣ Командная строка (CLI)

#### Базовая очистка файла:
```bash
silence_remover.exe input_podcast.mp3 output_clean.mp3
```

#### Очистка с использованием пресета:
```bash
silence_remover.exe interview.wav --preset pure
```

#### Полный цикл: Очистка + ИИ-распознавание (Groq) + Редактирование (DeepSeek):
```bash
silence_remover.exe lecture.mp4 lecture_clean.mp3 -t --groq-key gsk_... --deepseek-key sk-...
```

## 🔑 Настройка API-ключей (Переменные окружения)

Чтобы не вводить ключи каждый раз, вы можете добавить их в переменные окружения системы.

### Windows (PowerShell)
```powershell
$env:GROQ_API_KEY="gsk_ваш_ключ_groq"
$env:DEEPSEEK_API_KEY="sk-ваш_ключ_deepseek"
```

### Windows (CMD)
```cmd
set GROQ_API_KEY=gsk_ваш_ключ_groq
set DEEPSEEK_API_KEY=sk-ваш_ключ_deepseek
```

### Linux / macOS (Bash / Zsh)
```bash
export GROQ_API_KEY="gsk_ваш_ключ_groq"
export DEEPSEEK_API_KEY="sk-ваш_ключ_deepseek"
```

> 💡 **Где взять ключи:**
> - **Groq API Key (Бесплатно):** [console.groq.com](https://console.groq.com/)
> - **DeepSeek API Key:** [platform.deepseek.com](https://platform.deepseek.com/)

## 🎛️ Флаги и параметры CLI

| Флаг | Полное имя | Описание | По умолчанию |
| :--- | :--- | :--- | :--- |
| `-d` | `--db` | Порог тишины в дБ (чем больше число, тем больше вырезается) | `-35.0` |
| `-p` | `--preset` | Готовые пресеты: `pure` (-50dB), `normal` (-35dB), `noisy` (-25dB) | `normal` |
| `-m` | `--min-sec` | Минимальная длительность паузы для удаления (в секундах) | `0.4` |
| `-f` | `--format` | Выходной формат аудио (`mp3` или `wav`) | `mp3` |
| `-t` | `--transcribe` | Включить ИИ-распознавание речи в `.txt` | `выключено` |
| | `--groq-key` | Ключ Groq Whisper API | Переменная `GROQ_API_KEY` |
| | `--deepseek-key` | Ключ DeepSeek API для редактирования текста | Переменная `DEEPSEEK_API_KEY` |
| `-h` | `--help` | Показать интерактивную справку | — |
